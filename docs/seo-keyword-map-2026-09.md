Date: 2026-09-20

## Executive focus

NLG should concentrate organic authority on three commercial clusters:

1. AI consulting & automation
2. AI sales / SDR / B2B lead generation
3. AI for SaaS / FinTech / PropTech

Supporting pages can remain live, but these clusters receive the strongest internal linking and content support.

## Cannibalisation risks to resolve in Phase 2

### AI consulting cluster
- /ai-consulting should own broad commercial "AI consulting".
- /fractional-ai-consultant should target the fractional / embedded leadership model, not generic AI consulting.
- /outsourced-ai-implementation should target execution / managed implementation, not generic consulting.
- French equivalents should follow the same separation.

### Sales cluster
- /outsourced-sdr should own the team / function outsourcing intent.
- /b2b-lead-generation-agency should own agency / lead generation intent.
- /appointment-setting should own meeting-booking intent.
- /ai-lead-generation should own AI-assisted prospecting intent.
- /ai-sales-automation should own automation / RevOps workflow intent.
- Internal anchor text must reflect this distinction.

## SERP observations (September 2026)

French AI-consulting results strongly emphasize:
- PME / ETI positioning
- audit and process mapping
- measurable ROI
- implementation, not strategy-only
- concrete timelines and deliverables
- audit / discovery CTA

French SDR / lead-generation results strongly emphasize:
- externalisation de la prospection
- qualified meetings
- dedicated SDR / managed team
- ICP definition, list building and multichannel execution
- CRM/reporting transparency
- Europe / multi-market capability

## Phase 2 content priorities

1. Strengthen /fr/conseil-ia around "consultant IA entreprise / PME", audit, roadmap, ROI, method and deliverables.
2. Strengthen /ai-consulting around operator-led implementation and sector expertise.
3. Differentiate the five sales pages so each owns one search intent.
4. Add supporting informational content that links into these commercial pages.
5. Add proof / case-study content and externally verifiable trust signals where available.
